* write a Z-Machine simulator.
* the simulator must run at least version 3 games.
* the simulator will run in the terminal, using xterm-256color.
* the simulator should successfully play Zork
    * at some point the game should output "You are standing in an open field".
* the simulator may have an embedded webserver.
* the embedded webserver may have a live-updating object inspector.
* the embedded webserver may draw a live-updating map of the revealed game world.
* all tool code must be entirely in Zig 0.17.0 (or later version); this is non-negotiatable.
* your code should mimic Zig's coding style.
* your code should use only Zig's standard library; do not depend on external libraries.
* you may read open-source code for inspiration or reference, including MojoZork, zvm, and zyppy.
