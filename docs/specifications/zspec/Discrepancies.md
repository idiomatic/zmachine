# Discrepancy register

One row per point where the sources disagree or are silent.

| Kind | Meaning |
| --- | --- |
| Silence | The Standard doesn't say. |
| Ambiguity | The Standard can be read more than one way. |
| Error | The Standard is wrong about the original games or interpreters. |
| Disagreement | Interpreters differ. |
| Dependence | Infocom games rely on behavior outside the Standard. |
